Large FPS + Memory Monitor - Stencyl Engine Extension

Purpose
-------
Enabling this extension automatically places a larger FPS/memory display over
Stencyl's built-in stats monitor. There are no blocks and no game-side calls.

Displayed values
----------------
FPS: measured rendered frames per second / stage target frame rate
MEM: OpenFL System.totalMemoryNumber in MB

Install
-------
1. In Stencyl, open Settings > Extensions.
2. Install the ZIP.
3. Enable "Large FPS + Memory Monitor" for the game.
4. Save and rebuild/run the game.

The overlay is placed at the top-right of the stage and kept above Stencyl's
built-in monitor.
